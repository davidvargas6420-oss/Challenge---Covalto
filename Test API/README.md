# Consumo y validación de API Rick and Morty con Python

Aqui encontraras el proceso de Consumo dela API en [Rick and Morty](https://rickandmortyapi.com/) utilizando **Python**.  
Objetivo: Medir el tiempo de respuesta, validar el código de estado, comprobar la estructura del JSON y filtrar personajes principales vivos.

---

## 📋 Requisitos
- Python 3.8 o superior  
- Librería `requests` instalada (`pip install requests`)  
- Conexión a internet  

---

## Ejecución
1. Clona este repositorio o descarga los archivos.  
2. Verifica que tengas instalada la librería `requests`.  
3. Ejecuta el script principal desde la terminal:  
   ```bash
   python main.py
